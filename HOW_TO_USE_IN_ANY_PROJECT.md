# 🚀 How to Use ASP (Aegis Swarm Protocol) in ANY Project

The **ASP (Aegis Swarm Protocol)** is completely project-agnostic. You can inject this system into any existing or new software project (Web, Mobile, Backend, AI, Cloud Infrastructure, Game Dev) to instantly gain an autonomous, self-improving, specialized 9-agent engineering team configured according to the **Native Antigravity Standard**.

---

## 📦 Quick Start: 3-Step Setup

### Step 1: Copy `.agents` into Your Project Root
Copy the `.agents/` folder from this directory directly into the root directory of your target repository:

```bash
# Example (from your target project directory):
cp -r "C:/Users/hadev/Desktop/Antigravity-Agent-Swarm-OS/.agents" ./
```

Your project directory tree should look like:
```text
my-project/
├── .agents/
│   ├── custom-agents/             <-- Declarative dual-mode agent definitions
│   ├── rules/                     <-- Progressive disclosure rules (always_on / model_decision)
│   ├── schemas/                   <-- Explicit TaskState and structured event schemas
│   ├── telemetry/                 <-- Immutable append-only event ledger (event-ledger.jsonl)
│   ├── scripts/                   <-- Lightweight boundary guards & event validation scripts
│   ├── skills/                    <-- 45+ Production-grade open-source skills
│   ├── hooks.json                 <-- 4-Tier Progressive Quality Gate (pre-edit, post-task, pre-merge, pre-prod)
│   └── user_prefs.json            <-- Workspace state & HITL configuration
├── src/
├── package.json (or pyproject.toml, go.mod, Cargo.toml)
└── README.md
```

---

### Step 2: Configure Workspace Rule in Antigravity
Ensure that your Antigravity workspace points to `.agents/rules/01-core-principles.md`. Antigravity will automatically load the rules, declarative agents, and on-demand skills!

---

### Step 3: Activate the Lead Agent
Start your session by activating **POAI** (Lead Orchestrator):

> *"Activate POAI. Review the project requirements in `README.md` and formulate the milestone roadmap for Shift 1."*

## 🎨 The UXAI Visual Mockup & Approval Flow

When requesting any frontend layout or UI feature:
1. **UXAI** drafts the design prompt and calls `generate_image` to render a high-fidelity visual mockup.
2. UXAI presents the visual image directly to you via an interactive `ask_question` modal.
3. **Fai** only starts implementing the React/Tailwind components after you click **Approve**, ensuring pixel-perfect fidelity with zero guesswork.
